# Interactive Excel Sales Dashboard

## Project Overview

An interactive Excel dashboard built to analyze sales performance using sample transaction data from 2020–2021.

## Tools Used

* Microsoft Excel
* Excel formulas
* Interactive dropdown filters
* Charts and KPI cards

## Dashboard Features

* Total Sales Analysis
* Average Transaction Sales
* Units Sold
* Profit Analysis
* Region, Sales Person, and Product filters
* Four interactive charts

## Key Skills Demonstrated

* Data Analysis
* Data Visualization
* KPI Reporting
* Excel Dashboard Development
* Business Insights

## Dataset

The workbook contains 50 sample transactions dated 2020–2021. The data is for demonstration and learning purposes and does not represent actual current business performance.

## How to Use

1. Download `Sales_Dashboard.xlsx` from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard sheet.
4. Use the dropdown filters to explore sales performance.
